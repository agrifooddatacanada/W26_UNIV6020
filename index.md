# W26 UNIV6020 Schema Library

Students participating in the UNIV6020 Optional Module on Research Data Management in the W26 semester, were asked to create a data schema for an ongoing project or a fictitious project if they were a coursework student. This schema library contains the data schemas of the 38 students participating in the module.
